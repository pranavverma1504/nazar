# GPT Taste Skill Framework

## Core Objective
Force the AI model entirely out of standard boilerplate "AI slop" UI design. Do not use generic 3-column card layouts, flat purple-to-blue gradients, or uncalibrated margins.

## Configurable Dials
- DESIGN_VARIANCE: 9  (Maximize unique, high-end layouts)
- MOTION_INTENSITY: 9 (Optimize for heavy scroll-bound parallax systems)
- VISUAL_DENSITY: 5   (Cinematic whitespace distribution)

## Strict Animation Rules
1. PERFORMANCE: All animations must use hardware-accelerated CSS properties (`opacity`, `transform: translate3d`). Never animate layout properties like `top`, `left`, `width`, or `height`.
2. MATHEMATICAL EASING: Use custom `cubic-bezier` formulas or physics-based spring dampening equations instead of standard `linear` or `ease-in-out` curves.
3. SCROLL SYSTEMS: Prioritize layout stability during multi-layered parallax scrolling loops. Avoid jank and layout shifts.
